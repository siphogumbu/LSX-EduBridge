# 🌉 EduBridge

### Bridging learners to better education.

EduBridge is an **offline-first educational platform** designed to help learners identify learning gaps and receive targeted academic support.

## 🎯 Problem

Many learners struggle with school subjects because they do not have enough learning resources or personalised support. They may not know exactly which topics they are weak in, while teachers may not have enough time to provide individual support to every learner.

## 💡 Proposed Solution

EduBridge provides a simple digital learning pathway:

**Diagnostic Test → Identify Weak Area → Personalised Lesson → Practice Quiz → Progress Tracking**

The platform is designed to be accessible on mobile devices and can store learner progress locally on the device.

## ⭐ Importance and Impact

EduBridge is important because it can:

- Give learners a quick way to identify areas they need to improve.
- Provide targeted learning instead of giving every learner the same material.
- Support learners who have limited access to individual tutoring.
- Help learners practise at their own pace.
- Reduce dependence on continuous internet access for basic learning activities.
- Give teachers a foundation for identifying common learning gaps.
- Support more equal access to quality education.

## ▶️ Run the project

No installation is required for the basic prototype.

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Select **Start Diagnostic Test**.
4. Complete the assessment.
5. Explore the recommended lesson and practice quiz.

## 🌐 Deploy with GitHub Pages

1. Create a public GitHub repository called `EduBridge`.
2. Upload all files in this repository.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Click **Save**.

GitHub will provide a public website for the project.
